# Finance App

一个面向个人消费管理的财务指挥中心，适合部署在自己的服务器上使用。

它支持日常记账、固定订阅管理、连载/追更计划、月预算、统计分析、数据导出，以及基于 DeepSeek / OpenAI Compatible 接口的 AI 消费分析。

## 功能特性

- 用户注册与登录
  - 基于邀请码注册
  - JWT 鉴权
  - 登录限流

- 日常记账
  - 快速添加支出
  - 支持分类、金额、名称、日期
  - 支持批量导入 CSV 文本
  - 支持编辑和删除账单记录

- 固定订阅
  - 管理月付 / 季付 / 年付订阅
  - 每个订阅项可单独开启或关闭“订阅中”状态
  - 可设置和修改续订时间
  - 月付订阅在开启后，会按续订日期自动写入当月实际账单
  - 年付订阅会继续在仪表盘中提醒大额消费

- 连载 / 追更
  - 管理待购入的连载计划
  - 一键“结算本期”，自动写入账单并更新下一期计划

- 仪表盘
  - 查看本月预算、预期消费、实际支出
  - 显示本月已记入实际账单的订阅数量和金额
  - 对年付订阅进行大额消费提醒

- 统计中心
  - 日 / 月 / 年三种视图切换
  - 当日支出排行
  - 当月支出排行（默认前 10，可展开）
  - 年度支出排行
  - 分类统计、月度汇总、日均支出等信息

- AI 分析
  - 支持 DeepSeek 优先
  - 兼容 OpenAI 风格接口
  - 可对当前日 / 月 / 年支出发起分析
  - 支持在页面中保存 API Key、模型和接口地址

- 数据与部署
  - SQLite 单文件数据库
  - 兼容旧数据库结构，启动时自动补充缺失字段
  - 适合直接部署到自有服务器
  - 支持 JSON 全量备份与 CSV 导出

## 技术栈

- Node.js
- Express
- SQLite3
- JSON Web Token
- 原生静态前端页面

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，并填写你自己的配置：

```bash
cp .env.example .env
```

最少需要配置：

- `PORT`
- `JWT_SECRET`
- `ADMIN_INVITE_CODE`

### 3. 启动项目

```bash
npm start
```

默认启动入口仍然是：

```bash
node app.js
```

### 4. 运行测试

```bash
npm test
```

## 环境变量

项目支持的主要环境变量如下：

| 变量名 | 说明 |
| --- | --- |
| `PORT` | 服务监听端口 |
| `JWT_SECRET` | JWT 签名密钥，生产环境请使用强随机值 |
| `ADMIN_INVITE_CODE` | 注册邀请码 |
| `DB_FILE` | SQLite 数据库文件路径，默认是项目目录下的 `finance.db` |
| `NODE_ENV` | 运行环境，如 `production` / `development` / `test` |
| `TRUST_PROXY` | 服务器在反向代理后时可配置 |
| `RATE_LIMIT_WINDOW_MS` | 登录限流时间窗口 |
| `RATE_LIMIT_MAX` | 登录限流次数 |

## 数据库说明

- 默认使用 SQLite
- 不要求你手工迁移旧数据库
- 启动时会自动检查表和字段
- 对旧库采用“缺失即补充”的兼容方式，不会主动破坏现有数据

## AI 分析说明

- AI 设置保存在数据库中，按用户隔离
- 默认优先推荐使用 DeepSeek
- 当前数据库主要记录的是支出数据，没有独立收入表
- 因此 AI 分析会明确说明“当前仅基于支出数据分析”

## 适用场景

- 想把个人消费系统部署在自己的 VPS / 云服务器上
- 希望兼顾手动记账、订阅管理、连载购买计划和统计分析
- 希望保留 SQLite 单文件数据库，便于迁移和备份
